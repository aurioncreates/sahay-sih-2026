**Smart India Hackathon 2026**

Overview
Sahay is an AI-powered platform that helps SC citizens identify the correct credit or education loan scheme, 
calculate EMI, and locate the nearest eligible Channel Partner.

Tech Stack
- React
- FastAPI / Node.js
- PostgreSQL
- Rule-based Recommendation Engine
